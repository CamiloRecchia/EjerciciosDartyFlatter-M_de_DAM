# Programación Multimedia y Dispositivos Móviles

¡Bienvenido a mi repositorio de PMDM!

Soy **Camilo Villarroel Recchia**, estudiante de Desarrollo de Aplicaciones Multiplataforma (DAM).

En este repositorio voy a ir subiendo los ejercicios y prácticas que realice durante el curso de Programación Multimedia y Dispositivos Móviles, principalmente relacionados con **Dart y Flutter**.

La idea es tener todos los ejercicios organizados y poder ver cómo voy avanzando y aprendiendo a programar con estas tecnologías.

---

## Tecnologías utilizadas

Estas son algunas de las herramientas y tecnologías que estamos utilizando durante el curso:

- **Dart:** lenguaje de programación que estamos aprendiendo.
- **Flutter:** framework que utilizaremos para desarrollar aplicaciones multiplataforma.
- **Visual Studio Code:** editor de código.
- **Git y GitHub:** para guardar y organizar los ejercicios.

## Contenido del repositorio

El repositorio está organizado siguiendo los temas y las relaciones de ejercicios que vamos trabajando en clase.

### 1. Introducción a Dart

Primeros pasos con el lenguaje y sus principales características.

- Variables y constantes.
- Tipos de datos.
- Operadores.
- Cadenas de texto.
- Null Safety.
- Listas, Maps y Sets.
- Estructuras de control.

### 2. Funciones

Ejercicios para aprender a crear y utilizar funciones.

- Funciones básicas.
- Parámetros requeridos y opcionales.
- Parámetros nombrados.
- Funciones flecha.
- Funciones anónimas.
- Recursividad.
- Manipulación de listas.

### 3. Programación orientada a objetos

Introducción a las clases y objetos utilizando Dart.

- Clases y objetos.
- Atributos y métodos.
- Constructores.
- Herencia.
- Interfaces.
- Mixins.

### 4. Flutter

Introducción al desarrollo de aplicaciones utilizando Flutter.

Este apartado se irá completando conforme avancemos con el temario y empecemos a realizar ejercicios y proyectos con el framework.

---

## Sobre el repositorio

Este repositorio se irá actualizando durante el curso con nuevos ejercicios y prácticas.

Intentaré mantener los archivos ordenados, utilizar nombres claros y añadir comentarios cuando sean necesarios para entender mejor el funcionamiento del código.

El objetivo es ir mejorando poco a poco y aprender a desarrollar aplicaciones utilizando Dart y Flutter.
